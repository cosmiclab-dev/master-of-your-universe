# Master of Your Universe

Part B of the Applied Materials South Korea discovery tool (Zyeta). The player builds their new office in three stops:
team space, workcafé and meeting room. Each stop is one realistic diorama seen from one fixed camera. Every pick drops a
pin where it goes, and every step is painted into the same image by an AI edit. At the end the player picks a favourite
stop, can change one thing, and gets a photoreal eye-level render of it.

## Play on a laptop
- **Mac:** double-click `Start Game.command`. The first time, macOS may ask: right-click it, choose Open, then Open.
- **Windows:** double-click `Start Game (Windows).bat`.
- It starts a small local server (Python 3, nothing to install) and opens http://localhost:8777.
- You can also double-click `index.html`. That works for Nano Banana 2, OpenAI and fal, but Unsloth and edits of saved
  images need the server.

## Turn on photos with your Google AI Studio key
1. Double-click `Start Game.command` once. It creates `keys.env` in this folder and opens it.
2. Paste your key after `GEMINI_API_KEY=`, save, close the game window, and run Start Game again.
3. The game switches photos on by itself. The key stays in `keys.env` on this computer (locked to your user account) and is added by the local server, so it never reaches the browser, the zip or GitHub.

Billing: a Google AI Pro subscription does not cover the API. In Google AI Studio, enable billing on the key's project. Nano Banana 2 costs about $0.07 per 1K image and $0.10 per 2K image. The game makes the three space photos at 1K and the final photo at 2K, so about $0.30 to $0.40 per player.

## Free photo options
- **Cloudflare Workers AI** (about 170 photos a day free): make a free Cloudflare account, create an API token with the Workers AI permission, and put `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` in `keys.env`. The game switches it on by itself if there's no Gemini key.
- **Pollinations** (no key at all): pick it in Facilitator → Photos. Slow (about one photo every 15 seconds) and may add a small watermark.
Both make photos from a text description, so they follow the player's picks but not the exact 3D layout. For the client demo, Nano Banana 2 gives the most faithful result.

## Image models (Settings, the gear button)
| Choice | What to enter |
| --- | --- |
| Offline | Nothing. Uses images in `images/` and shows pins. |
| Nano Banana 2 | Gemini API key from Google AI Studio. Model `gemini-3.1-flash-image` (falls back to the preview name). |
| OpenAI | API key, model `gpt-image-1` or newer. |
| fal.ai | Key, a model for new images (default `fal-ai/qwen-image`) and one for edits (default `fal-ai/qwen-image-edit`). |
| Unsloth (local) | Address `http://127.0.0.1:8888/v1`, your `sk-unsloth-…` key, then press Test and pick the Qwen-Image 2.1 model. |
| OpenAI-compatible | Any server with `/images/generations` and `/images/edits` (OpenArt, Together and similar gateways). |

Keys are stored in the browser on that device only. They are never written into the code.

## Image pack
Settings → Image pack → Generate missing makes the empty platform plus 16 layout dioramas with the chosen model, all
edited from one master image so the camera never moves. When the game runs through the local server they are saved into
`images/` as `DIO-*.png`, so every later player starts instantly. Copy any prompt from the same panel to run it by hand.

## Deploy on Vercel
1. Import this repo in Vercel. No framework, no build step.
2. Optional environment variables so players never see a key: `GEMINI_API_KEY`, `OPENAI_API_KEY`, `FAL_KEY`.
   `PROXY_EXTRA_HOSTS` adds hosts for an OpenAI-compatible provider (comma-separated).
3. Commit the `images/DIO-*.png` files you generated locally so the hosted game starts instantly.
Vercel can't reach the Unsloth server on your laptop, so use an API provider there. Responses are capped at 4.5 MB,
so Gemini renders at 1K through Vercel.

## Data
Every finished game is saved on the device (Settings → Export CSV) and, with the local server, in `sessions/`
(`/api/export.csv`). Fields: role, every pick by step, free text, seconds per step, favourite stop, change one thing.

## Files
- `index.html`, `css/game.css`, `js/game.js`: the game
- `js/providers.js`: one image layer for every provider, with caching
- `js/data.js`: generated by `tools/build_data.py` from `tools/prompts.json` (options, pins, edit wording, prompts)
- `server.py`: local server and proxy; `api/proxy.js`, `api/health.js`: the same on Vercel
